# Hexagon chess board generator

This project aim is to simplify the exeperience of playing various hexagonal chess variants. Model generated by it
can be interconnected in any configuration, allowing to play *classic* hexagonal variants like Glinsky chess or
even more obscure one like starchess.

# Models

The models are generated based on `config.yaml` file. Default one can be found at `src/configs/default.conf.yaml`.
To fit the model your needs, you have a few options to edit the config and generate the STL models.


## (Recommended) Streamlit app

Visit the [webpage](https://hex-chess-board-generator.streamlit.app/), adjust the parameters, and click **download**.

## local Python

System requirements: install `uv` and `openscad` libraries.


UV [installation guide](https://docs.astral.sh/uv/getting-started/installation/).

OpenSCAD [installation guide](https://openscad.org/downloads.html).


Next clone the repo and move to the directory:
```bash
git clone https://github.com/AIn0n/hex-chess-board-generator && cd 2Mkb
```


Create UV virtual environment:
```bash
uv venv
```


Activate the environment:
```bash
source .venv/bin/activate
```


Install project requirements:
```bash
uv sync
```


Run the script:
```bash
uv run generate
```

By default STL file can be found at `build/` directory.
